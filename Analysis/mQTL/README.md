# Association between var-CpG methylation and genetic features

This directory contains code for testing associations between var-CpG methylation and local genetic features.

## Overview

Associations between var-CpG methylation and genetic features are tested using linear models implemented in the `MatrixEQTL` R package.

Analyses are restricted to intermediate-frequency var-CpGs:

```text
5% < AF < 95%
````

In total, 2,816,359 var-CpGs meeting this frequency criterion are tested.

Three classes of genetic features are analyzed separately:

* copy number of the target var-CpG itself;
* copy number of nearby var-CpGs; and
* nearby genetic variants that do not directly cause CpG gain or loss.

## Association models

For each association test, var-CpG methylation M-value is used as the response variable and the corresponding genetic feature is used as the predictor.

The models include the following covariates:

* sex; and
* the first five population principal components.

Nearby genetic features are tested within:

```text
10 kb
```

of the target var-CpG.

Coordinates for nearby-feature analyses are projected onto the GRCh38 backbone.

## Genetic feature classes

### Self-copy number

The copy number of the target var-CpG itself is tested for association with methylation at the same var-CpG.

### Nearby var-CpG copy number

Copy number of neighboring var-CpGs within 10 kb is tested for association with methylation at the target var-CpG.

### Nearby non-CpG-altering variants

Nearby genetic variants that do not directly create or disrupt the target CpG are tested within 10 kb of the target var-CpG.

## Permutation calibration

Association significance is evaluated using FastQTL-style permutation calibration.

For each target var-CpG:

```text
1,000 permutations
```

are performed to generate null association statistics.

A beta distribution is fitted to the permutation-derived null statistics, and the observed nominal P value is converted to a beta-adjusted empirical P value.

## Multiple testing correction

Multiple testing is controlled at an estimated false discovery rate of 5% using the `qvalue` R package.

Significant associations are defined using:

```text
FDR < 0.05
```

## Sensitivity analyses

Association analyses are repeated using additional minor allele frequency thresholds:

```text
MAF > 5%
MAF > 10%
MAF > 20%
```

These analyses are used to evaluate the robustness of the genetic associations across different allele-frequency thresholds.

## Input

Typical inputs include:

* var-CpG methylation M-value matrices;
* var-CpG copy-number matrices;
* nearby genetic variant genotypes;
* var-CpG allele-frequency information;
* sex annotations;
* population principal components; and
* GRCh38-projected genomic coordinates.

## Output

Outputs generated by these workflows include:

* nominal association P values;
* permutation-calibrated empirical P values;
* beta-adjusted P values;
* q values;
* significant var-CpG–genetic feature associations; and
* association results across different MAF thresholds.

## Software requirements

Major software and R packages used in these analyses include:

* R
* `MatrixEQTL`
* `qvalue`

Additional software versions, parameters and statistical procedures are provided in the corresponding scripts and in the Methods of the manuscript.

## Reproducibility

Scripts in this directory correspond to the analyses of associations between var-CpG methylation and genetic features described in the manuscript.

Analysis-specific input files, covariates, filtering criteria, permutation procedures and multiple-testing corrections are documented in the corresponding scripts and in the Methods of the manuscript.
