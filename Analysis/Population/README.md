# Population-associated analyses

This directory contains code for population-associated analyses of CpG abundance, DNA methylation, var-CpG copy number, integrated var-CpG signals and genetic–epigenetic differentiation across human populations.

## Overview

The workflows in this directory characterize population-associated variation in the human pan-epigenome using complementary CpG-level representations:

- population-specific CpG and methylation differences;
- population structure and variance partitioning;
- directional-selection enrichment; and
- genetic and epigenetic differentiation.

Unless otherwise stated, analyses are restricted to autosomal CpGs or var-CpGs.

## Diversity across methylomes

For each haplotype-resolved methylome, CpG abundance is summarized as the total number of detected CpGs and genome-wide methylation as the median methylation level across all CpGs.

Summary statistics are calculated by:

- population;
- continental group; and
- sex, where applicable.

Methylation levels are represented as proportions ranging from 0 to 1.

To quantify between-population variability within each continental group, population-level median CpG abundance or methylation is first calculated. The median absolute deviation (MAD) of these population-level values is then calculated within each continental group.

Differences between two groups are assessed using two-sided Wilcoxon rank-sum tests, whereas comparisons involving more than two populations or continental groups use Kruskal–Wallis tests.

Additional tests include:

- Pearson’s chi-squared tests for categorical distributions;
- Fisher’s exact tests for genomic-feature enrichment; and
- Benjamini–Hochberg correction for multiple testing.

Unless otherwise specified, FDR < 0.05 is considered significant.

## Variance partitioning and population structure

Population-associated epigenomic variation is quantified using three complementary CpG-level representations.

### Shared-CpG methylation

Shared CpGs are defined as autosomal reference CpGs present in more than 99% of analyzed haplotypes.

The response variable is DNA methylation level.

### Var-CpG copy number

Var-CpGs are restricted to autosomal sites with intermediate presence frequencies:

```text
5% < AF < 95%
````

CpG copy number is represented as:

```text
0, 1 or 2
```

copies per individual.

### Integrated var-CpG representation

The integrated model uses the one-dimensional latent representation combining CpG copy number and methylation generated by the encoder–decoder workflow.

For each CpG or var-CpG, a linear model is fitted using either continental group or population label as the explanatory variable.

The proportion of variation associated with population structure is summarized using the model R².

Mean R² values across CpGs or var-CpGs are used to summarize population-associated variation within each representation.

Because the three representations describe different biological measurements, R² values are interpreted within each representation rather than directly compared across representations.

## Permutation analysis

Statistical significance of population-associated variance is assessed using label permutation.

Continental group or population labels are randomly permuted across individuals while the CpG-level response matrices are retained.

For each analysis:

```text
1,000 permutations
```

are performed.

For each permutation, the CpG-level models are refitted and the mean R² is recalculated.

Empirical one-sided permutation P values are calculated as the proportion of permuted mean R² values greater than or equal to the observed mean R².

## Principal component analysis

Principal component analysis (PCA) is used to visualize population structure captured by:

* shared-CpG methylation; and
* var-CpG copy number.

CpGs or var-CpGs with more than 10% missing values are excluded.

Remaining missing values are imputed using the mean value of the corresponding CpG or var-CpG across individuals.

PCA is performed on centered and scaled matrices.

## Population-specific CpG and methylation analyses

Population-specific CpGs and var-CpGs are identified through pairwise comparisons between continental groups.

Three representations are evaluated:

* shared-CpG methylation;
* var-CpG copy number; and
* the integrated var-CpG score.

### Shared CpGs

Shared-CpG methylation differences are tested using linear models implemented in `limma`.

CpGs with more than 10% missing values are excluded.

Methylation β-values are transformed to M-values before statistical modeling.

For each pairwise comparison:

```text
M-value ~ continental group + sex
```

Empirical Bayes moderation is used to obtain CpG-level test statistics.

Statistical testing is performed using M-values, whereas effect sizes are reported as differences in median β-values between groups.

### Var-CpGs

Analogous `limma` models are fitted using either:

* CpG copy number; or
* the integrated score scaled from 0 to 1.

Var-CpGs with more than 10% missing values are excluded.

The model includes continental group and sex as predictors.

Unless otherwise specified, CpGs and var-CpGs are classified as population-specific when:

```text
absolute between-group difference > 0.20
FDR < 0.05
```

The effect-size measure, Δ, corresponds to:

* the difference in median β-value for shared-CpG methylation;
* the difference in scaled CpG copy number for var-CpGs; or
* the difference in scaled integrated score.

A sensitivity analysis applies the same effect-size threshold together with:

```text
P < 5 × 10^-8
```

## Enrichment at loci under directional selection

Genomic loci showing evidence of directional selection are harmonized to GRCh38 coordinates using UCSC `liftOver`.

CpG-altering variants are defined as variants that create or disrupt a CpG dinucleotide.

Variants are retained when:

```text
MAF > 1%
```

Enrichment is assessed by comparing the proportion of CpG-altering variants among directional-selection loci with that of eligible non-CpG-altering variants from the same HPRC2 variant set.

Variants are matched using:

* chromosome;
* position;
* reference allele; and
* alternative allele.

Enrichment is evaluated using Pearson’s chi-squared test.

## Genetic and epigenetic differentiation

For each var-CpG, genetic differentiation and integrated var-CpG differentiation are quantified by comparing each focal continental group with all remaining groups.

### Genetic differentiation

Genetic differentiation is estimated using FST for the variant responsible for CpG gain or loss.

FST is calculated using `VCFtools` with the Weir and Cockerham estimator.

### Integrated differentiation

Differentiation of the integrated var-CpG signal is estimated using PST:

```text
PST = σb² / (σb² + 2σw²)
```

where:

* `σb²` is the variance between the focal and comparison groups; and
* `σw²` is the mean within-group variance.

PST ranges from 0 to 1, with larger values indicating greater between-group differentiation of the integrated var-CpG signal.

To identify var-CpGs showing divergence from that expected based on genetic differentiation, PST is regressed on FST separately for each focal-versus-rest comparison.

The fitted PST represents the expected integrated differentiation given the observed FST.

Var-CpGs are classified as having lower-than-expected integrated differentiation when:

```text
expected PST - observed PST > 0.05
```

and higher-than-expected integrated differentiation when:

```text
observed PST - expected PST > 0.05
```

These categories use a descriptive residual threshold rather than a formal significance test.

## Input

Typical inputs include:

* CpG abundance measurements;
* shared-CpG methylation matrices;
* var-CpG copy-number matrices;
* integrated var-CpG scores;
* population and continental-group annotations;
* sex annotations;
* genetic variant files;
* directional-selection loci;
* genomic annotations; and
* GRCh38-projected coordinates.

## Output

Outputs generated by these workflows include:

* population-level CpG and methylation summaries;
* MAD estimates across populations;
* statistical comparisons between groups;
* population-associated R² estimates;
* permutation-based empirical P values;
* PCA coordinates;
* population-specific CpG and var-CpG lists;
* directional-selection enrichment results;
* FST and PST estimates; and
* lower- and higher-than-expected integrated differentiation classifications.

## Software requirements

Major software and R packages used in these analyses include:

* R v4.4.1
* `limma`
* `VCFtools` v0.1.16
* UCSC `liftOver`
* standard R statistical functions for Wilcoxon, Kruskal–Wallis, chi-squared and Fisher’s exact tests

Additional software versions and parameters are provided in the corresponding scripts and in the Methods of the manuscript.
