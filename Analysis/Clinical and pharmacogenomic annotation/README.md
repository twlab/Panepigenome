# Clinical and pharmacogenomic annotation of CpG-altering variants

This directory contains code for annotating CpG-altering variants with clinical and pharmacogenomic information and for evaluating their enrichment relative to background genetic variants.

## Overview

Clinical annotations are obtained from ClinVar, and pharmacogenomic annotations are obtained from ClinPGx.

Variants are harmonized and matched to external annotation records using:

- chromosome;
- genomic position;
- reference allele; and
- alternative allele.

The workflows in this directory include:

- annotation of CpG-altering variants using ClinVar and ClinPGx;
- enrichment analysis of clinical and pharmacogenomic annotations;
- annotation-specific analyses across genomic contexts; and
- identification of population-specific clinically or pharmacogenomically annotated var-CpGs.

## Clinical and pharmacogenomic annotations

ClinVar annotations are evaluated both overall and by clinical-significance category, including:

- pathogenic or likely pathogenic;
- benign or likely benign;
- risk; and
- protective variants.

Pharmacogenomic annotations are obtained from ClinPGx and matched to the HPRC2 variant set after genome-build and allele-orientation harmonization.

## Variant filtering

Unless otherwise specified, enrichment analyses are restricted to variants with:

```text
MAF > 1%
````

Background variants consist of other common variants from the same HPRC2 variant set.

## Enrichment analysis

For each annotation category, the proportion of CpG-altering variants carrying the annotation is compared with the corresponding proportion among background variants.

Enrichment is evaluated using Fisher’s exact test.

Where applicable, P values are adjusted for multiple testing using the Benjamini–Hochberg procedure.

Fold enrichment is calculated as:

```text
Fold enrichment =
proportion of CpG-altering variants in the annotation category
/
proportion of background variants in the annotation category
```

Values greater than 1 indicate enrichment among CpG-altering variants.

## Genomic-context analysis

Promoters are defined as strand-aware 2-kb intervals upstream of annotated transcription start sites using GRCh38 gene annotations.

Promoter and CpG island (CGI) annotations are used to assess whether methylation differences among clinically and pharmacogenomically annotated var-CpGs vary across genomic contexts.

Methylation comparisons are not further stratified by CpG frequency because genome-wide methylation shows negligible correlation with CpG presence frequency for both reference and non-reference CpGs.

## Population-specific annotations

Population-specific clinical and pharmacogenomic var-CpGs are identified by intersecting annotated CpG-altering variants with population-specific var-CpGs identified from pairwise comparisons between continental groups.

These analyses are restricted to variants with:

```text
MAF > 5%
```

Population-specific annotations are evaluated using both:

* the CpG gain/loss model; and
* the integrated CpG copy number and methylation model.

## Input

Typical inputs include:

* HPRC2 genetic variant calls;
* CpG-altering variant annotations;
* ClinVar annotations;
* ClinPGx annotations;
* variant allele frequencies;
* GRCh38 promoter annotations;
* CpG island annotations;
* var-CpG methylation measurements; and
* population-specific var-CpG results.

## Output

Outputs generated by these workflows include:

* ClinVar-annotated CpG-altering variants;
* ClinPGx-annotated CpG-altering variants;
* clinical-significance classifications;
* enrichment estimates;
* Fisher’s exact test P values;
* multiple-testing-adjusted P values;
* genomic-context-specific methylation summaries; and
* population-specific clinical and pharmacogenomic var-CpG lists.

## Software requirements

Major software and analysis tools used in these workflows include:

* R
* `bedtools`
* standard Unix command-line utilities
* standard R functions for Fisher’s exact test and Benjamini–Hochberg correction

Additional software versions, annotation releases and analysis parameters are provided in the corresponding scripts and in the Methods of the manuscript.

## Reproducibility

Scripts in this directory correspond to the clinical and pharmacogenomic annotation analyses described in the manuscript.

Analysis-specific input files, filtering criteria, annotation categories, genomic-context definitions and statistical procedures are documented in the corresponding scripts and in the Methods of the manuscript.
