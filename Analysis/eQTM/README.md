# Association between promoter var-CpG methylation and transcript expression

This directory contains code for testing associations between promoter var-CpG methylation and transcript expression.

## Overview

Associations are evaluated in individuals with matched DNA methylation, genetic-variant and Iso-Seq transcript-expression data.

Transcript-specific promoters are defined as strand-aware 2-kb regions upstream of annotated transcription start sites (TSSs).

In total, 97,712 promoter var-CpGs associated with 165,223 annotated transcripts are evaluated.

## Association models

For each promoter var-CpG–transcript pair, transcript expression is modeled as a function of the var-CpG methylation M-value.

The base model includes:

- var-CpG methylation M-value;
- sex;
- the first five genotype principal components; and
- one expression PEER factor associated with technical batch effects.

A second model additionally includes CpG copy number, encoded as:

```text
0, 1 or 2
````

copies per individual.

This model is used to evaluate whether the methylation–expression association remains after adjustment for the underlying CpG-altering variant.

## Association classification

Associations significant both before and after adjustment for CpG copy number are classified as:

```text
Robust to adjustment for the underlying variant
```

Associations detected only after adjustment for CpG copy number are classified as:

```text
Conditional methylation–expression associations
```

## Multiple testing correction

Multiple testing is controlled using a two-stage hierarchical procedure.

### Transcript-level testing

For each transcript, association P values across promoter var-CpGs are combined using the aggregated Cauchy association test (ACAT).

Transcript-level P values are then adjusted across transcripts using the `qvalue` procedure.

Transcripts with:

```text
q < 0.05
```

are retained for var-CpG-level testing.

### Var-CpG-level testing

Within each significant transcript, promoter var-CpG association P values are adjusted using the Benjamini–Hochberg procedure.

Promoter var-CpG–transcript pairs with:

```text
within-transcript FDR < 0.05
```

are considered significant.

## Input

Typical inputs include:

* promoter var-CpG methylation M-values;
* Iso-Seq transcript-expression measurements;
* CpG copy-number matrices;
* transcript-specific promoter annotations;
* sex annotations;
* genotype principal components; and
* expression PEER factors.

## Output

Outputs generated by these workflows include:

* promoter var-CpG–transcript association statistics;
* association results before and after adjustment for CpG copy number;
* ACAT transcript-level P values;
* transcript-level q values;
* within-transcript FDR values;
* significant promoter var-CpG–transcript pairs; and
* classification of associations as robust or conditional.

## Software requirements

Major software and R packages used in these analyses include:

* R
* `qvalue`
* an implementation of the aggregated Cauchy association test (ACAT)
* standard R functions for linear modeling and Benjamini–Hochberg correction

Additional software versions, parameters and statistical procedures are provided in the corresponding scripts and in the Methods of the manuscript.

## Reproducibility

Scripts in this directory correspond to the promoter var-CpG methylation and transcript-expression association analyses described in the manuscript.

Analysis-specific input files, promoter definitions, covariates, statistical models and multiple-testing procedures are documented in the corresponding scripts and in the Methods of the manuscript.
