# Mediation and variant-by-methylation interaction analyses

This directory contains code for evaluating whether var-CpG methylation mediates genetic effects on transcript expression and whether CpG-altering variants interact with methylation to influence transcript expression.

## Overview

Two complementary analyses are performed:

- mediation analysis of genetic effects through var-CpG methylation; and
- variant-by-methylation interaction analysis.

Both analyses use CpG copy number as the genetic variable, var-CpG methylation as the epigenetic variable and transcript expression as the outcome.

CpG copy number is encoded as:

```text
0, 1 or 2
````

copies per individual.

Models are adjusted for:

* sex;
* the first five principal components derived from genome-wide genotypes; and
* one expression PEER factor associated with technical batch effects.

## Mediation analysis

Mediation analysis is used to test whether var-CpG methylation statistically mediates the association between CpG gain or loss and transcript expression.

Two models are fitted for each var-CpG–transcript pair.

### Mediator model

Var-CpG methylation is modeled as a function of CpG copy number and covariates:

```text
methylation ~ CpG copy number + sex + genotype PCs + PEER factor
```

### Outcome model

Transcript expression is modeled as a function of CpG copy number, var-CpG methylation and the same covariates:

```text
expression ~ CpG copy number + methylation + sex + genotype PCs + PEER factor
```

Mediation is evaluated using the `mediation` R package with nonparametric bootstrap simulations.

Analyses are initially performed using:

```text
100 bootstrap simulations
```

Associations yielding a bootstrap P value of zero are rerun using:

```text
10,000 bootstrap simulations
```

To reduce computational burden, mediation tests are restricted to var-CpG–transcript pairs for which CpG copy number is associated with var-CpG methylation in the mediator model at:

```text
P < 0.1
```

Average causal mediation effect (ACME) P values are adjusted using the Benjamini–Hochberg procedure.

Statistical mediation is considered significant at:

```text
FDR < 0.05
```

## Variant-by-methylation interaction analysis

Variant-by-methylation interactions are tested using linear models in which transcript expression is modeled as a function of CpG copy number, var-CpG methylation and their interaction.

The model is:

```text
expression ~ CpG copy number + methylation +
             CpG copy number × methylation +
             sex + genotype PCs + PEER factor
```

Var-CpG methylation is represented using the corresponding M-value.

Interaction analyses are restricted to var-CpG–transcript pairs showing both:

* a significant CpG copy number–expression association; and
* a significant methylation–expression association after adjustment for CpG copy number.

Both associations are required to satisfy:

```text
FDR < 0.05
```

Interaction-term P values are adjusted using the Benjamini–Hochberg procedure.

Variant-by-methylation interactions are considered significant at:

```text
FDR < 0.05
```

## Input

Typical inputs include:

* var-CpG methylation M-values;
* CpG copy-number matrices;
* transcript-expression measurements;
* sex annotations;
* genotype principal components; and
* expression PEER factors.

## Output

Outputs generated by these workflows include:

* mediator-model statistics;
* outcome-model statistics;
* average causal mediation effect estimates;
* mediation bootstrap P values;
* FDR-adjusted mediation results;
* variant-by-methylation interaction coefficients;
* interaction-term P values; and
* FDR-adjusted interaction results.

## Software requirements

Major software and R packages used in these analyses include:

* R
* `mediation`
* standard R functions for linear modeling
* standard R functions for Benjamini–Hochberg multiple-testing correction

Additional software versions, parameters and statistical procedures are provided in the corresponding scripts and in the Methods of the manuscript.

## Reproducibility

Scripts in this directory correspond to the mediation and variant-by-methylation interaction analyses described in the manuscript.

Analysis-specific input files, covariates, filtering criteria, bootstrap settings and multiple-testing procedures are documented in the corresponding scripts and in the Methods of the manuscript.
