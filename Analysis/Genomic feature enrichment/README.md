# Genomic feature enrichment

This directory contains code for enrichment analyses of var-CpGs across ChromHMM states and other regulatory genomic annotations.

## Overview

Regulatory annotations are used to characterize the genomic context of var-CpGs showing genetic associations with DNA methylation.

The workflows in this directory include:

- processing of ChromHMM annotations for GM12878 lymphoblastoid cell lines (LCLs);
- coordinate conversion of regulatory annotations from hg19 to GRCh38;
- integration of LCL super-enhancer and gene annotations;
- definition of foreground and background var-CpG sets; and
- enrichment testing across ChromHMM states and regulatory elements.

## Regulatory annotations

ChromHMM annotations for GM12878 LCLs are obtained from the ENCODE Broad ChromHMM resource.

Coordinates are converted from hg19 to GRCh38 using UCSC `liftOver` and the `hg19ToHg38.over.chain.gz` chain file.

Additional annotations include:

- LCL super-enhancers from SEdb; and
- gene annotations from the UCSC Genome Browser.

## Foreground and background sets

The foreground set consists of var-CpGs whose methylation is significantly associated with all three genetic feature classes:

- self-copy number;
- nearby var-CpG copy number; and
- nearby non-CpG-altering genetic variants.

The background set consists of all var-CpGs whose methylation is significantly associated with at least one of these three genetic feature classes.

## Enrichment analysis

For each ChromHMM state or regulatory element, enrichment is evaluated using Fisher’s exact test.

P values are adjusted for multiple testing using the Benjamini–Hochberg procedure.

Significant enrichment is defined as:

```text
FDR < 0.05
````

Fold enrichment is calculated as:

```text
Fold enrichment =
proportion of foreground var-CpGs overlapping the annotation
/
proportion of background var-CpGs overlapping the annotation
```

Values greater than 1 indicate enrichment of the annotation among foreground var-CpGs.

## Input

Typical inputs include:

* var-CpG coordinates;
* genetic-association results;
* GM12878 ChromHMM annotations;
* LCL super-enhancer annotations;
* gene annotations; and
* GRCh38-converted regulatory annotation files.

## Output

Outputs generated by these workflows include:

* overlap counts for foreground and background var-CpGs;
* Fisher’s exact test P values;
* Benjamini–Hochberg-adjusted FDR values;
* fold-enrichment estimates; and
* summary tables used for downstream visualization.

## Software requirements

Major software and command-line utilities used in these analyses include:

* R
* UCSC `liftOver`
* `bedtools`
* standard Unix command-line utilities

Additional software versions and analysis parameters are provided in the corresponding scripts and in the Methods of the manuscript.

## Reproducibility

Scripts in this directory correspond to the genomic feature enrichment analyses described in the manuscript.

Analysis-specific inputs, statistical procedures and annotation sources are documented in the corresponding scripts and in the Methods of the manuscript.
