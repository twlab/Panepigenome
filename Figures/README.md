# Figure reproduction

This directory contains code used to reproduce the main, Extended Data and Supplementary figures presented in:

**Dong Z. et al. Human pan-epigenome represents epigenomic diversity.**

## Overview

Figure-generation scripts are organized according to the corresponding manuscript figures and panels where applicable.

The workflows in this directory include:

- generation of main figures;
- generation of Extended Data figures;
- generation of Supplementary figures; and
- preparation of processed plotting datasets and summary statistics used for figure generation.

Where applicable, figure-specific scripts correspond directly to individual manuscript panels to facilitate reproducibility.
